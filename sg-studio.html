Quản lý & sửa Modules và Scripts ngay trên Windows

Mở trực tiếp thư mục Modules / Scripts — mọi thay đổi được ghi thẳng vào đĩa. Gợi ý code học từ toàn bộ script đã có.

✏️ Sửa & lưu trực tiếp

Đọc/ghi thẳng vào tệp trên đĩa qua File System Access API (Chrome / Edge trên Windows). Tạo, đổi tên, nhân bản, xóa tệp bằng chuột phải.

🧠 Gợi ý thông minh

Khi gõ, ứng dụng học từ tất cả script & module trong thư mục: tên biến, hàm, thuộc tính, hostname… Gợi ý dạng “bóng mờ” — nhấn Tab để nhận. Ctrl+Space mở danh sách đầy đủ.

🎨 Hỗ trợ .sgmodule & .js

Tô sáng cú pháp riêng cho Surge module ([Script], [MITM], pattern…) và JavaScript ($request, $persistentStore…), kèm gợi ý thuộc tính môi trường.
